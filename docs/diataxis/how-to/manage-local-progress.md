# Como gerenciar o progresso local

Marcas de leitura e posição em Stories são guardadas pelo navegador deste dispositivo. A identidade usa certificação, simulado e tentativa para separar execuções.

## Retomar

Abra a mesma tentativa no mesmo perfil do navegador. O app restaura marcas e posição se o material continuar disponível. Conteúdo e progresso são dados separados.

## Mover para outro dispositivo

O produto não sincroniza progresso. Copiar arquivos `data/` transfere conteúdo, não o `localStorage`. Um navegador diferente começa sem as marcas anteriores.

## Reiniciar

Use os controles do app para limpar as marcas oferecidas, ou as configurações do navegador para apagar dados do site. Isso pode também remover cache offline e posição local; não apaga arquivos em `data/`.
