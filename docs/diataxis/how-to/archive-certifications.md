# Arquivar certificações

Use a galeria para marcar uma certificação como aprovada ou como estudo concluído e manter a biblioteca de estudo focada no que está ativo.

1. Abra a certificação na área de estudo e selecione **Archive certification**.
2. Escolha **Passed** ou **Finished studying** e confirme em **Archive**.
3. Abra **Gallery** na barra superior para consultar cartões ativos e arquivados.
4. Para consultar um item arquivado, selecione **Open study**. Ele continua arquivado enquanto você o consulta.
5. Para voltar a certificação aos seletores, use **Restore to active** na galeria.

A data do arquivamento é automática. O status é privado e fica no armazenamento deste navegador; limpar os dados do site remove esse estado. A galeria não publica nem exporta os cartões. Veja a [referência da interface](../reference/interface-and-shortcuts.md#certification-gallery-e-arquivamento).
